Python Photo Slideshow Album

A desktop photo slideshow application built with Python,
Tkinter, and Pillow.

## Features
- Display a collection of photos
- Automatically switch images every two seconds
- Play and stop slideshow controls
- Simple graphical user interface

## Technologies Used
- Python
- Tkinter
- Pillow

## Installation

Install the dependency:

```bash
python -m pip install -r requirements.txt
```

## Project Structure

```text
photo-slideshow-album/
```

## Run the Application

```bash
python photo_slideshow.py
```
